## Códigos usados para evaluar la performance de los modelos de deep learning

El directorio `src/statistical_downscaling` contiene la implementación de las métricas usadas para evaluar el desempeño determinístico y probabilístico de los modelos de downscaling estadístico.

El directorio `notebooks/` contiene las notebooks  para calcular y visualizar las métricas usadas para evaluar el desempeño de los modelos.
